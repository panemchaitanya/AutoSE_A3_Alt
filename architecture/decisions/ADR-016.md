# ADR-016: Exclude assignment README from independent reviewer context

- Status: Accepted correction, hosted trial pending
- Decision areas: D3, D8
- Amends: ADR003 and ADR008

## Context

Assignment README.md contains pipeline decisions, results and provenance.
The fresh reviewer copy excluded workflow/results/architecture artifacts,
but not this assignment README. That leaves an indirect influence path.
Earlier review claims establish filtering only, not complete independence.
The original upstream README.rst is ordinary source documentation.

## Decision

Exclude assignment README.md from both proposed diff and clean reviewer
checkout. Preserve upstream README.rst, source and tests. Keep all original
pipeline evidence outside the reviewer's input. Review is still not a
hardened sandbox; source comments may contain influence and Python remains
arbitrary execution. No historical review is retroactively upgraded.

## Alternatives

Leaving README available risks reintroducing excluded reasoning. Deleting
all documentation would remove normal project context unnecessarily.

## Consequences

A narrower information boundary, not proof against every covert influence.
New real reviews are needed to verify this revised implementation. E2 was
run under an earlier harness and is not validation of the final boundary.
