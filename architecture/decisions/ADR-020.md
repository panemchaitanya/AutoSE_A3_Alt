# ADR-020: Reuse A1 analysis without repeating its MCP demonstration in A3

## Status
Proposed for future fresh A3 runs, late work on 24 November 2026.
Not applied to an already-running attempt or used to reset an exhausted retry.

## Context
The live A3 stage table requires reuse of the A1 skill to produce a spec with
testable acceptance criteria. It does not require an MCP invocation. The A1
brief separately requires an MCP integration demonstration for its submission.
Our original skill incorporates that requirement, and our full-skill prompt
and judge carried it into A3. This overconstrains A3 stage 1. A friend's
reported advice prompted a source check, not an unverified rubric change.

## Decision
Preserve the original skill file unchanged. Append a shared explicit A3 reuse
profile to its effective prompt, and give the same profile to the integrity
judge. Override only the MCP-invocation prerequisite and associated mandatory
skipped-MCP disclosure. Record repository-local analysis with no MCP used.
Inspect real repository files for code facts, and preserve uncertainty when
an external fact cannot be verified. Never label a file read as an MCP call.
Keep SRS, REGISTER, VALIDATION, consistent version selection, source links,
assumption/question links, honest basis/gates, and testable acceptance criteria.
A missing MCP call alone cannot fail the stage or force an item to CLARIFY.

## Alternatives
Retaining full A1 MCP compliance would conflate separate assignment scopes.
Removing the integrity judge entirely would also remove useful checks on
invented evidence and unsupported readiness. Neither is adopted.

## Consequences
This changes the effective prompt and harness digest. Existing checkpoints
cannot silently inherit a pass, and failed/exhausted attempts remain failed.
No claim is made that removing an MCP prerequisite fixes independent source,
assumption or consistency defects. Autonomous evidence is still required.
The original A1 submission and its tool-use requirement are not changed.
